# Contributing to TodoListDemo

Thank you for your interest in contributing to TodoListDemo!

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Create a feature branch**: `git checkout -b feature/my-new-feature`.
3. **Commit your changes**: Follow clean commit message conventions.
4. **Push to the branch**: `git push origin feature/my-new-feature`.
5. **Submit a Pull Request**.

## Submodule Guidelines

- Each submodule implementation must be contained within its assigned category directory.
- Every submodule must include a clear, informative `README.md`.
- Code should be clean, idiomatic, and follow standard practices for that language/framework.
